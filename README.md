# Multivariate Analysis of the Hotel Industry

## Project Overview
Academic project, focused on applying multivariate statistical techniques to a hotel booking dataset containing 200,000 observations. The project aimed to identify factors influencing hotel room prices and booking preferences.

## Project Objectives
- Analyse hotel booking data and identify relevant patterns.
- Examine the factors influencing room prices through multiple linear regression.
- Reduce data complexity using factor analysis.
- Classify hotel bookings using Linear Discriminant Analysis (LDA).
- Analyse accommodation preferences through logistic regression.
- Evaluate model performance and predictive accuracy.

## Methodology
- Descriptive Statistical Analysis
- Multiple Linear Regression
- Factor Analysis
- Linear Discriminant Analysis (LDA)
- Multinomial and Binary Logistic Regression
- Hypothesis Testing
- ROC Curve Analysis
- Model Validation

## Tools & Technologies
- IBM SPSS Statistics
- Statistical Analysis
- Multivariate Data Analysis

## Key Skills
Data Analysis, Statistical Modelling, Data Interpretation, Critical Thinking and Quantitative Analysis.
